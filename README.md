# Laboratorio: Serverless REST API con AWS Lambda y API Gateway

## Roles para este taller
- **Agente guía (este)**: Te llevo paso a paso, te hago pensar en arquitectura, te recuerdo checkpoints, te ayudo a documentar y criticar decisiones.
- **Agente de código (otro)**: Al que le envías los prompts con el contexto. **Tú** decides qué aceptar/rechazar y lo documentas como evidencia.

## Estructura
- `orders-api/` - Proyecto Maven Java 17
- `docs/CHECKLIST.md` - Seguimiento por fases
- `evidence/` - Prompts, decisiones, críticas al agente, pruebas, diagramas, capturas
- `README.md` - Documentación del taller (diseño API, checkpoints, comparativas, etc.)

## Cómo trabajar
1. **Diseñar antes de codificar** (sección 4). No pidas código aún.
2. **Usar prompt estructurado** al agente de código (sección 15).
3. **Guardar TODO** en `evidence/` (prompts, decisiones, por qué).
4. **Criticar** >=3 decisiones (sección 16).
5. **Predecir antes de extender** (sección 17) - escribir predicción antes de pedir a IA.
